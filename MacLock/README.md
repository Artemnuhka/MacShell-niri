# MacLock для niri

Экран блокировки из MacShell с отдельным процессом Quickshell, PAM и `ext-session-lock-v1`. Устанавливается основным `./install.sh`; отдельное копирование в конфигурацию Hyprland не требуется.

```sh
~/.local/bin/macshell-lock
```

Установщик добавляет `Super+L`, если сочетание свободно. Helper проверяет доступность PAM-сервиса `swaylock`, выбирает PAM-совместимый Quickshell, запускает новый locker при необходимости и запрашивает блокировку через IPC. После разблокировки процесс завершается; следующий запуск создаёт новый объект session-lock.

Внешний вид, шрифт и стиль часов меняются в Settings → Lock Screen. Roboto Flex, Nunito и Noto Serif Display устанавливаются основным установщиком в пользовательский каталог из комплектных OFL-ресурсов.

Для визуального предпросмотра (он **не блокирует** сеанс):

```sh
MACLOCK_PREVIEW=1 timeout 6 ~/.local/bin/macshell-lock
```

Настоящая блокирующая поверхность имеет непрозрачный фон во время входной анимации. Состояние блокировки определяется протоколом compositor, а не наличием окна предпросмотра. PAM должен работать до использования MacLock как основного locker.
